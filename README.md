# DefiMarsh

Simplifies DeFi protocol monitoring by tracking transaction data and liquidity pool changes in real-time.

With DefiMarsh, you get a lightweight tool that stays out of your way.

**What you get**

- Simplifies DeFi protocol monitoring by
- tracking transaction data and liquidity
- pool changes in real-time

## Key Features

- Simplifies DeFi protocol monitoring by
- tracking transaction data and liquidity
- pool changes in real-time

## Technology Stack

- python
- python framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/DefiMarsh.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
